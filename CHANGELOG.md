# Changelog

## 0.4.1 — public beta

- First focused public package of the successful exterior screened Poisson path.
- Camera-visible oriented patch capture, bounded numerical cleanup, enclosed-shell removal, and geometry screening.
- Working 500,000-patch preset with a 2,000,000-ray-probe budget, depth 10, and point weight 16.
- Static mesh file loader, synthetic demo, visual and API workflows, installation helper, compatibility notes, and focused regression tests.
- Earlier voxel-fill, projection, and skin/core experiments remain in the separate development pack.

This package reconstructs surfaces; it does not guarantee exact detail preservation or certify printability.
